ASD

ASD（自閉スペクトラム傾向）のある子どもへのサポートアイデア

コミュニケーションや感覚に独自の傾向がある子どもへ

📌 コミュニケーション支援

「なるべく散らかさないでね」より「新しいおもちゃを出すときは前のを片付けてから」といった形で、具体的・明確な指示を出すことが基本とされています。また、話し言葉より絵カードや文字などの視覚情報のほうが理解しやすいという特性に合わせた対応が広く推奨されています。

📌 こだわり・切り替え

「あと10分で片付けするよ」「あと5分だよ」のように事前に終わりを認識させることが有効で、急かすような口調でなくゆったりしたトーンで伝えることも大事とされています。

📌 感覚過敏

ASDの子どもの約60〜90%に感覚過敏または鈍麻などの感覚の問題があると報告されており、特に聴覚・視覚・触覚への配慮が中心です。無理に慣れさせるのでなく、少しずつ子どものペースで進めることが大切と強調されています。

📌 TEACCH（構造化）

「いつ・どこで・何を・どのようにやるか・いつ終わりか」を視覚的に示し、物理的・時間的・活動的に環境を整理することで安心して行動できるようになるとされており、世界45カ国以上で実践されているアプローチです。

📌 自己肯定感・感情サポート

スモールステップで「できた」を増やし、のぞましい行動をしたときにストレートな表現でほめることが定着につながるという考え方が一貫しています。常同行動（くるくる回る・ジャンプなど）は不安や緊張を和らげる手段であることが多く、無理にやめさせると逆にストレスを高めることがあるとも指摘されています。

📌 専門的療育

療育によって本人が適切な支援を受け、周囲が特性を十分に理解できるようになると自己肯定感が高まり、二次的な困り感の予防につながるとされています。

参照：LITALICO発達ナビ、すまいるナビゲーター、発達特性情報ポータルサイト、AIAI VISIT、スタジオそら 他
ADHD

ADHD（注意欠如・多動の傾向）のある子どもへのサポートアイデア

不注意・多動・衝動の傾向がある子どもへ

📌 ASDとの大きな違い

ASDの子は「なぜそれがNGなのか分からない」ケースが多いのに対し、ADHDの子は「NGとは分かっているが、つい不適切な言動をとってしまう」ことが多いという点があります。支援の方向性が少し変わってくるポイントです。

📌 不注意の根本

情報を一時的に頭の中で保持しながら整理・処理する「ワーキングメモリ」の弱さがあります。これは「忘れっぽい性格」ではなく、脳の機能的な特性です。

📌 多動性への視点

動いていなければ気分的に落ち着かないという子も多いため、食事の際の配膳やプリント配りなど動いてよい役割を与えてあげるとよく、「お手伝い行動」としてほめる機会にもなるという視点が実践的です。

📌 感情の爆発と二次的な困り感

不注意優勢では不安やうつが多く、多動・衝動優勢では好ましくない行動や依存が多くなるという2つの悪循環パターンがあり、二次的な困り感の予防という観点が支援の大きな目的になっています。

📌 ASDとADHDの共通点と違い

「構造化・予測可能性」はどちらにも有効ながら、その理由が違う（ASD＝見通しがないと不安になる、ADHD＝ワーキングメモリの補助が必要）という対比が見えてきます。

参照：LITALICO発達ナビ・ジュニア、スタジオそら、AIAI VISIT、国立精神・神経医療研究センター、日本精神神経学会 他
HSP・HSC

HSP・HSC（高感受性の傾向）のある子どもへのサポートアイデア

ひといちばい敏感で、深く感じる子どもへ

📌 ASD・ADHDとの決定的な違い

HSCと発達特性の違いは「他人の気持ちが理解できるかどうか」という点にあり、HSCは逆に他人の気持ちを敏感に読み取ることができるとされています。この「共感力の高さ」が、HSPの核心的な特徴であり強みでもあります。

📌 疲れやすさの特徴

不快なことだけでなく、楽しいことでも刺激が多いとHSCの子どもは疲れてしまいます。体の疲れはわかりやすいが、心の疲れは本人も自覚していないことがあるため注意が必要です。遊園地から帰ってぐったりしていても、それは楽しくなかったのではなく消耗しているということです。

📌 自己肯定感の形成

「HSCの子はそこまでしつけする必要はない」「生活習慣でいえば、睡眠だけしっかりしていればOK」「勉強や生活習慣を身につけることは、自己肯定感の上に積み上がっていく」という児童精神科医・明橋大二先生の言葉が示す通り、自己肯定感の土台作りが最優先とされています。

参照：明橋大二『HSCの子育てハッピーアドバイス』、エレイン・N・アーロン、ベネッセ、東京ガスウチコト、LITALICO 他
LD：音韻型

LD：読み書きの傾向（音韻型ディスレクシア）のある子どもへのサポートアイデア

音と文字を結びつける部分に独自の傾向がある子どもへ

📌 なぜ「読めない」でなく「極端に遅い」か

1文字を読むのに時間がかかり間違えることもあるという状態では、読むだけで疲れてしまって意味を把握する段階まで至らない。その結果、語彙や知識が不足して学業不振が著しくなり、さらには心身症や不登校といった二次的な困り感の状態になってしまうこともあるというメカニズムが重要です。

📌 支援の基本方針

「医学的に今のところできることはないが、教育的にできることはたくさんある。まずは読み書きの負担を軽減すること、強みを活かして内容の理解に力を入れること」という専門家の言葉が核心を突いています。「治す」ではなく「迂回路を作る」という発想の転換です。

📌 ICT活用の現実的な壁

保護者が特定の機器の使用や配慮を学校にお願いしても許可されないケースがあります。決められた使い方しか許可していない学校が多いのが現状で、そういう場合は学校ではなく教育委員会や第三者委員会に声を上げることが重要という指摘があります。ASDとLDは併存することも少なくありません。

参照：国立成育医療研究センター、NPO法人エッジ、浜松市子育て情報ぴっぴ、LITALICO、日本財団ジャーナル 他
LD：視覚認知型

LD：視覚情報処理の傾向（視覚認知型）のある子どもへのサポートアイデア

目で見た情報の処理に独自の傾向がある子どもへ

📌 音韻型との根本的な違い

ディスレクシアの症状は大きく「文字の読み方がわからない（音韻処理不全）」タイプと「文字の形がわからない（視覚情報処理不全）」タイプに分けられるとされており、支援の方向が変わります。

📌 見え方の特徴

文字がぼやける、黒いかたまりになっている、逆さまに見える、図形に見えるなど違った見え方になってしまい認知の仕方が異なるといった体験が報告されています。本人にとっては「これが普通」に感じていることが多く、周囲に伝えにくい点が特徴的です。

📌 「見て写す」が効かない

試写・なぞり書きによる漢字学習は視覚認知が弱い子どもには労力と時間が必要なうえ効果が出にくく、視覚認知が弱い場合は「音声で覚える」「意味で関連付けて覚える」方法が有効とされています。

📌 ビジョントレーニングの注意点

視覚機能の問題を訓練することで改善を図るアプローチだが、万能ではなく、まず視覚機能に問題があるかを専門の検査で確認してから取り入れることが重要とされています。音韻認識型と視覚処理型、2つのLDは「同じ読み書きの困難でも入口が全く違う」ことが鮮明です。

参照：発達特性教育推進センター、LITALICO発達ナビ、浜松市ぴっぴ、コペルプラス、スペースシップアース 他
LDの4種比較

LD（限局性学習症）の4種類 ― 傾向と特性の全体比較

読み・書き・算数、それぞれの特性を整理して理解する

📌 LDに共通すること

全タイプ共通：知的能力に遅れはない。特定の学習領域のみ著しく困難。脳の神経特性による先天的なもの。努力不足・理解不足ではない。複数のタイプが重なることも多い（特に読字と書字）。

📌 書字の傾向の特殊性

「読めるけど書けない」という状態が存在し、その原因は視覚情報処理・音韻処理・協調運動のいずれか、または複数が関与しており、人によって原因が異なるという点が重要です。

📌 算数の傾向の見落とされやすさ

算数の傾向の発症率は5〜7%とされており、ディスグラフィア・ディスレクシアと同程度の割合なので、決してまれなタイプではありません。「単に算数が苦手」との区別が難しい分、見過ごされやすいです。

📌 ASDとLDの併存

LDはADHD・ASDと高率で併存します。不注意由来か認知特性由来かの見極めが重要です。

参照：LITALICO発達ナビ・ジュニア、マドレクリニック、ブレインクリニック、スタジオそら、触るグリフ、全国地域生活支援機構 他
書字の傾向

書字の傾向（ディスグラフィア）のある子どもへのサポートアイデア

「書く」ことに独自の傾向がある子どもへ

📌 最も重要な出発点

「字が書けない」原因は「見る力が弱い」「音韻処理が苦手」「協調運動の困難」と複数あるため、書けない原因を明確にしてそれぞれに対処していく必要があります。他のLDタイプよりも「原因の見極め」が特に重要な傾向といえます。

📌 よくある誤った対応

ディスグラフィアは、たくさん練習するだけでは字を書けるようになりにくい傾向であり、量よりも質に重点をおいた訓練が必要とされています。「漢字を10回書いて覚えなさい」は逆効果になりやすいです。

📌 多感覚学習の効果

部首パーツの成り立ちと意味的つながりで漢字が覚えられる、実際に部首パーツと漢字全体に触れることで漢字の形の記憶を増強できる、最後に手で書くことで運動イメージに紐づけられる、という複数の感覚を組み合わせた記憶の多重符号化が記憶痕跡を強めるとされており、視覚だけでなく触覚・聴覚を組み合わせることが有効です。

📌 協調運動との関係

発達性協調運動症のある子どもへの感覚統合療法を10回実施したところ13例中9例で書字困難に関する主訴の改善が認められたという報告もあり、作業療法との連携の意義が示されています。

参照：LITALICOジュニア・発達ナビ、ベネッセ、SOLE個別最適学習ラボ、触るグリフ、まなびかたlab 他
算数の傾向

算数の傾向（ディスカリキュリア）のある子どもへのサポートアイデア

数の理解や計算に独自の傾向がある子どもへ

📌 「どこでつまずいているか」の構造

数処理→数概念→ワーキングメモリという順に土台となって積み重なり、互いに影響し合いながら算数の傾向を引き起こしていると考えられているため、土台が揺らいでいる段階から支援を始める必要があります。

📌 九九の暗唱に固執しない

聴覚的な短期記憶が弱いお子さんには九九の暗唱は苦しいが、聴覚認知は弱くても視覚認知はできることが多いので、九九の表を見ながら「かける数の列はどう変わるか」などパターンを理解させると、九九が言えなくても九九ができないという問題は解決できる（筑波大学教授・熊谷氏）という指摘は実践的です。

📌 筆算の支援も原因によって異なる

視空間認知能力が低い場合はマス目のあるノートで対応し、継次処理能力が低い場合は計算の手続きを文章にした手順カードを使うと効果的とされています。

📌 読字の困難との重なり

読字の困難は算数の傾向のある子どものうち40〜60%を占めるという報告があるため、文章題が苦手な場合は算数の理解だけでなく文章を読む困難も確認することが必要です。

参照：まなびたすく（筑波大学教授・熊谷恵子氏）、触るグリフ、天神メディア、KNOT、発達特性教育推進センター、キズキ家学 他
愛着の課題との違い

愛着の課題と発達特性・HSPの違い ― 見分け方の整理

「どちらか」ではなく、傾向を読むための参考として

📌 最も捉えやすい見分け方

愛着の課題による疑似ADHDの場合、環境が安定し愛着を築ける人に出会うことで症状が軽減されるケースが多く、一部の人では症状が完全に消失したということもあります。「安心できる場所・人のそばでは落ち着く」のは愛着の課題、「どこでも特性が変わらない」のが発達特性の傾向です。

📌 ルール・片付けの「中身の違い」

ADHDの子どもは片付けやルールを守るのが苦手だが、愛着の課題の子どもは片付けやルールを守ること自体が気持ちいいと感じる感情が育っていない可能性があります。ADHDへの行動の支援を行っても愛着の課題の子どもには効果が薄く、愛着の課題の場合は感情を育む支援が必要という整理が実践的です。

📌 HSPと愛着の課題の違い

愛着の課題は安全な環境や安定したケアを受けてこなかったための後天的な困難であるのに対し、発達特性（HSP含む）は多くの場合生まれつきの脳機能の偏りによるものという軸が整理の起点になります。HSPは「感じやすいが人を信頼できる」、愛着の課題は「人を信頼できない感覚が根底にある」という違いが本質的です。

📌 「両方ある」ケース

発達特性と愛着の課題は「どちらか」ではなく「両方ある」ことが珍しくない。ASD特性ゆえに親が育てにくさを感じ→不適切な愛着関係が築きにくくなる→愛着の課題も発症、ということもあります。疑わしい場合は専門機関（発達外来・児童精神科・発達支援センター）に相談を。

参照：かもみーる、障害者ドットコム、ONE LOVE（米澤好史氏）、みんなの教育技術（高山恵子氏）、コペルプラス 他

特性のある子どもたちは、「なぜそうなるのか」を理解してから動くタイプが多く、単なる反復や暗記より、ルール・パターン・構造の把握が得意な場合があります。

8つの思考法・アプローチ

🔍
パターン発見思考
Pattern Recognition

数や形に「くり返しのルール」を見つける思考法。一度ルールが見えると、解くスピードが一気に上がる。

算数・数学 ★ 入門 宿題で使える
どんな思考法？

「数や形に法則はないか？」と探すクセをつける方法です。数列・図形・計算の問題でくり返しを見つけると、全体のしくみが一瞬でわかるようになります。

使いかた例（算数・理科・国語）
📌 かけ算九九を自分でつくってみる（算数） 「3×1=3、3×2=6…」→ 3ずつ増えている！ → じゃあ3×8は？ を計算せずに予測できるようになる。
やってみよう（ステップ）
  1. 問題の数字や形をいくつか並べて書き出す
  2. 「ふえかた・へりかた・くり返し」がないか探す
  3. ルールをことばで言ってみる（例：「2ずつ増える！」）
  4. ルールを使って次の答えを予測してみる
⏪
逆算思考（ゴール逆読み）
Backward Thinking

「答えから逆にたどる」思考法。「ゴールがわかっているなら、逆から考えれば最短コース！」という合理主義者向けの発想。

算数・文章題 ★★ 中級 文章題に強い
どんな思考法？

ゴール（答え）から逆方向に考えて、「そのためには何が必要か？」と順番にさかのぼる方法。遠回りに見える問題も、ゴールから逆に考えると最短ルートで解けることがあります。

使いかた例（算数・理科）
📌 「リンゴを5つ食べたら3つ残った。最初は何個？」（算数） ふつう：□−5＝3 → 答え8
逆算で：3（残った）＋5（食べた）＝8 → 逆から足すと一目でわかる！
やってみよう（ステップ）
  1. 「最後の状態（答え）」を確認する
  2. 「その直前は何だった？」と一步ずつ戻る
  3. スタートにたどり着いたら確認する
🌿
マインドマップ思考
Mind Mapping

頭の中の考えを「ツリー状の絵」で広げる方法。視覚優位な子に特に合いやすく、知識の「つながり」が見えてくる。

整理・まとめ ★ 入門 自主学習に最適
どんな思考法？

紙の真ん中にテーマを書き、そこから枝を伸ばしてキーワードを広げていく方法です。文字だけでなく、色・矢印・絵を使うのがコツ。脳の「連想のしくみ」にぴったり合っているので、記憶に残りやすく、理解が深まります。

使いかた例（全教科に使える）
📌 「わり算」のマインドマップ（算数） 中心：わり算 → 枝①「何に使う？」→「おやつを分ける」「時間を計る」
枝②「どうやる？」→「九九をさかのぼる」「筆算で計算」

📌 理科の「植物のからだ」・国語の「登場人物」もマップで整理できる テーマを変えれば、どの教科でもそのまま使える。
やってみよう（ステップ）
  1. 白い紙の真ん中にテーマを書いて○で囲む
  2. そこから線を伸ばしてキーワードを書く（枝）
  3. 枝からさらに枝を伸ばしてどんどん広げる
  4. 好きな色でぬったり絵を描いたりして完成！
🪄
「もし〜だったら？」思考
What If Thinking

「もし条件が変わったら？」と仮定して考える方法。正解を探すより「可能性を広げる」遊び感覚で楽しめる。

創造的思考 ★ 入門 発想力に◎
どんな思考法？

「もし〜だったら？」という問いを自分で立てて、答えを自由に想像する思考法です。正解がないから失敗しない。「ありえない仮定」ほどおもしろいアイデアが生まれやすく、算数の「もし数が変わったら？」という使いかたが算数力アップにもつながります。

使いかた例（算数・理科・国語）
📌 「もし答えが100じゃなくて10だったら？」（算数） 問題：□×8＝100 → もし答えが10だったら □×8＝10 → □は1.25？
「小数ってそういう意味か！」と理解が広がる。

📌 理科・国語でも 「もし植物に光が当たらなかったら？」（理科の予想）
「もし主人公が別の選択をしていたら？」（国語の読解）
やってみよう（ステップ）
  1. 問題をひとつ選ぶ
  2. 「もし数字が違ったら？」「もし条件が逆だったら？」と聞いてみる
  3. 答えがどう変わるか予想して試す
  4. 気づいたことをメモしておく
🧩
分解思考（チャンク分け）
Chunking / Decomposition

大きな問題を「小さなかたまり」に分けて考える方法。「一気に全部やる」より「小さく分けて順番に」が断然ラク。

算数・文章題 ★ 入門 宿題で使える
どんな思考法？

「大きくてむずかしい問題」を、自分が扱えるサイズに切り分けてから解く方法です。特性のある子は「全体を一気に処理するのが苦手」なことが多いので、この思考法が特に力を発揮します。「まず何をわかればいいか？」だけを考えます。

使いかた例（算数・国語・理科）
📌 「123＋456の計算」（算数） 一気に計算するのではなく…
①一の位だけ：3＋6＝9
②十の位だけ：20＋50＝70
③百の位だけ：100＋400＝500
④合計：9＋70＋500＝579

📌 国語・理科でも 長い文章題 →「登場人物」「起きたこと」「気持ち」に分けて読む
実験レポート →「目的」「方法」「結果」「考察」と分ける
やってみよう（ステップ）
  1. 問題を読んで「何を求めるか」だけ確認する
  2. 問題を2〜3つのかたまりに切り分けて書く
  3. かたまりをひとつずつ順番に解く
  4. 最後に全部をつなげて答えを出す
🔧
SCAMPER思考
Substitute · Combine · Adapt · Modify · Put to other uses · Eliminate · Reverse

「置き換え・組み合わせ・逆にする」など7つの視点でアイデアを強制的に広げるフレームワーク。

アイデア発想 ★★ 中級 自由研究に◎
どんな思考法？

7つの質問を使って、ひとつのテーマからたくさんのアイデアを出す方法です。「何か変えたら？」「組み合わせたら？」という問いが、考えのストッパーを外してくれます。自由研究・作文・図工のアイデア出しに特に強いです。

7つの問いかけ

S：別のものに置き換えたら？
C：組み合わせたら？
A：他のものに応用したら？
M：大きく・小さく・形を変えたら？
P：別の使い方をしたら？
E：なくしたら・減らしたら？
R：逆にしたら？順番を変えたら？

自由研究での使いかた例
📌 テーマ「植物の観察」をSCAMPERで広げる S：水を別の液体（お茶・砂糖水）に替えたら？
R：逆さに吊るして育てたら？
M：光の量を変えたら？
🖼️
視覚化思考（絵にする）
Visual Thinking

問題の内容を「絵・図・表」に変換する思考法。文章が苦手でも、絵にすれば一瞬で状況が見える。

算数・文章題 ★ 入門 視覚優位に最適
どんな思考法？

文章題の内容を読んだとき、「言葉のまま理解しようとしない」のがコツです。すぐに図や絵を描いてみることで、何が分かっていて何が分からないかが一目でわかります。特に視覚優位な子に強力な方法です。

使いかた例（算数・理科・国語）
📌 「バスに8人が乗っていて、3人降りて5人乗った。今は？」（算数） 文字だけで考えず、バスの絵を描いて人を〇で表す。
〇〇〇〇〇〇〇〇 → −3 → 〇〇〇〇〇 → +5 → 〇〇〇〇〇〇〇〇〇〇
数えると10人！

📌 理科・国語でも 理科の予想 → 実験の手順を絵と矢印で書いてからやってみる
国語の読解 → 場面ごとの出来事を時系列の図にして整理する
やってみよう（ステップ）
  1. 問題を読んで、出てくるものを絵・記号で書く
  2. 「増えた・減った・動いた」を矢印で表す
  3. 絵を見ながら答えを考える
  4. 慣れたら線分図・テープ図にチャレンジ！
💬
情意レベル言語化法
Certainty-Level Verbalization

考えが出てこないとき、「自分の考えがどのくらい確かか」を表す言葉を最初につけると、モヤっとした考えがするする言葉になって出てくる。

自分で使う ★ 入門 詰まったときに
「情意レベル」ってなに？

自分の考えについて、「どのくらい確かだと感じているか」のことを情意レベルといいます。「わからない」と感じているときでも、頭の中にはすでにモヤっとした考えの芽があります。そのモヤがどのくらい確かかを表す言葉を最初につけるだけで、考えが言葉の形を取り始め、するする出てくるようになります。

確かさを表す5つの言葉
📊 確かさが強い順 → 弱い順 🔴 ぜったい 〜！
🟠 きっと 〜だよ
🟡 たぶん 〜だと思う
🟢 もしかしたら 〜かな
🔵 ひょっとしたら 〜かもしれない
使いかた

考えが出てこないとき、この5つの中から「今の自分の確かさ」に一番近い言葉を選んで、考えの前につけるだけ。言葉が出てきたら、正しいかどうかを気にせず、どんどん続けて口に出していきます。

使いかた例（算数・理科・国語）
📌 答えが全然わからないとき（算数） 紙の言葉を見て、今の確かさに近いものを選ぶ
「ひょっとしたら……10より大きい数かもしれない」
「もしかしたら、足し算を使うのかな」
「たぶん、まず分けて考えるといいと思う」
「きっと、答えは20くらいだよ」
→ 言葉が出るたびに、次の考えが引き出されてくる！

📌 理科・国語でも 理科の予想 →「たぶん、水が多い方が早く育つと思う」
国語の読解 →「もしかしたら、主人公はさみしかったのかな」
おうちの方へ：用意するのはこれだけ

上の5つの言葉を紙に書いて、子どもの手元に置いておくだけで準備完了です。子どもが詰まったとき、「この中でどれが今の気持ちに近い？」とさりげなく指さすだけでOKです。

なぜ特性のある子に合うの？

「正しいことしか言えない」というプレッシャーで思考がフリーズしやすい子に特に効果的です。確かさが低い言葉から始めれば間違えてもOK。自分の確かさのレベルを自分で選ぶことで、考えるハードルが一気に下がります。

🌱 これは「才能の設計図」として使ってほしい

🔭
「できないことの補完」ではなく
「できることの拡張」へ

宿題を終わらせるだけのツールとして使うのではなく、「この子はパターンを見つけるのがとても速い。ロジカルに考える力がある」など、才能の輪郭を見つけるヒントとして使ってみてください。思考法との相性は、そのまま将来輝ける分野のサインかもしれません。

🤝
口頭の注意より、
紙の上の図を「一緒に見る」

口頭で「こうやって考えて」と言うと、特性のある子は「怒られている」と受け取りやすいことがあります。でも、紙の上に図や言葉を書いて一緒に見ると、向き合う相手が「問題」になる。「親子 vs 課題」という協力体制が自然と生まれます。
